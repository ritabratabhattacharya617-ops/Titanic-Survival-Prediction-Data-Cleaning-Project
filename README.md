# Week 1 — ML Fundamentals + Data Preprocessing

Completed from the supplied Week 1 course PDF.

The PDF requires:
- Assignment 1: load a dataset and summarize `.info()` and `.describe()`.
- Assignment 2: handle missing data using mean/median imputation.
- Assignment 3: encode categorical variables using LabelEncoder and OneHotEncoder.
- Mini Project 1: Titanic Survival Prediction — clean missing data, encode Sex and Embarked, visualize age distribution, and output a cleaned CSV.

The Titanic `train.csv` used here is the standard Kaggle Titanic training-format dataset (891 rows, 12 columns). Kaggle's competition page confirms that `train.csv` contains 891 passengers and the survival ground truth.
